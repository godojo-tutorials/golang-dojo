# Privacy Policy

*Last updated: February 22, 2026*

## 1. Overview

This Privacy Policy describes how Godojo (godojo.dev) collects, uses, and protects user information.

Godojo is a free educational resource for learning the Go programming language. We do not require registration, do not directly collect personal data, and do not sell data to third parties.

## 2. Data We Collect

### Automatically Collected Data

When you visit our site, the following technical information is automatically collected:

- **Analytics data** — page views, visit duration, navigation between pages (via Vercel Analytics)
- **Technical data** — browser type, operating system, screen resolution, browser language
- **Performance data** — Core Web Vitals metrics (LCP, FID, CLS)

### Data We Do NOT Collect

- Names, email addresses, phone numbers
- Payment card information
- Precise location (GPS)
- Account credentials (usernames, passwords)

## 3. How We Use Data

Collected data is used exclusively for:

- Improving content quality and user experience
- Analyzing lesson and section popularity
- Optimizing site performance
- Identifying and fixing technical issues

## 4. Third-Party Services

We use the following third-party services:

| Service | Purpose | Policy |
|---------|---------|--------|
| Vercel | Hosting and analytics | [vercel.com/legal/privacy-policy](https://vercel.com/legal/privacy-policy) |
| Cloudflare | DNS and protection | [cloudflare.com/privacypolicy](https://www.cloudflare.com/privacypolicy/) |
| GitHub | Source code | [docs.github.com/site-policy/privacy-policies](https://docs.github.com/en/site-policy/privacy-policies) |

## 5. Cookies

For detailed information about cookies, see our [Cookie Policy](/en/cookies/).

## 6. Your Rights

You have the right to:

- Know what data is collected about you
- Request deletion of your data
- Opt out of analytics data collection (using ad blockers or browser Do Not Track settings)

## 7. Security

The site transmits data over the secure HTTPS protocol. We do not store personal data on our servers.

## 8. Changes to This Policy

We may update this policy. Changes take effect upon publication on this page. We recommend checking for updates periodically.

## 9. Contact

For privacy questions: [GitHub Issues](https://github.com/godojo-tutorials/golang-dojo/issues)
