# Политика конфиденциальности

*Последнее обновление: 22 февраля 2026 г.*

## 1. Общие сведения

Настоящая Политика конфиденциальности описывает, как Godojo (далее — «мы», «наш сайт», godojo.dev) собирает, использует и защищает информацию пользователей.

Godojo — бесплатный образовательный ресурс по языку программирования Go. Мы не требуем регистрации, не собираем персональные данные напрямую и не продаём данные третьим лицам.

## 2. Какие данные мы собираем

### Автоматически собираемые данные

При посещении сайта автоматически собирается техническая информация:

- **Данные аналитики** — просмотры страниц, длительность визитов, переходы между страницами (через Vercel Analytics)
- **Технические данные** — тип браузера, операционная система, разрешение экрана, язык браузера
- **Данные о производительности** — метрики Core Web Vitals (LCP, FID, CLS)

### Данные, которые мы НЕ собираем

- Имена, email-адреса, номера телефонов
- Данные платёжных карт
- Точное местоположение (GPS)
- Учётные данные (логины, пароли)

## 3. Цели использования данных

Собранные данные используются исключительно для:

- Улучшения качества контента и пользовательского опыта
- Анализа популярности уроков и разделов
- Оптимизации производительности сайта
- Выявления и устранения технических проблем

## 4. Сторонние сервисы

Мы используем следующие сторонние сервисы:

| Сервис | Назначение | Политика |
|--------|------------|----------|
| Vercel | Хостинг и аналитика | [vercel.com/legal/privacy-policy](https://vercel.com/legal/privacy-policy) |
| Cloudflare | DNS и защита | [cloudflare.com/privacypolicy](https://www.cloudflare.com/privacypolicy/) |
| GitHub | Исходный код | [docs.github.com/site-policy/privacy-policies](https://docs.github.com/en/site-policy/privacy-policies) |

## 5. Файлы cookie

Подробная информация о файлах cookie — на странице [Политика cookies](/ru/cookies/).

## 6. Права пользователей

Вы имеете право:

- Узнать, какие данные о вас собираются
- Запросить удаление ваших данных
- Отказаться от сбора аналитических данных (блокировщики рекламы или настройки браузера Do Not Track)

## 7. Безопасность

Сайт передаёт данные по защищённому протоколу HTTPS. Мы не храним персональные данные на своих серверах.

## 8. Изменения политики

Мы можем обновлять эту политику. Изменения вступают в силу с момента публикации на этой странице. Рекомендуем периодически проверять обновления.

## 9. Контакты

По вопросам конфиденциальности: [GitHub Issues](https://github.com/godojo-tutorials/golang-dojo/issues)
